# Ruzy para Chrome — demonstração

Abra chrome://extensions, ative Modo do desenvolvedor e carregue esta pasta sem compactação. Habilite acesso a URLs de arquivos nos detalhes da extensão.

Depois abra demo/relatorio-demo.html no mesmo navegador. Veja INSTALAR-RUZY.md na raiz do projeto.
Esta versão não acessa o Azure; todos os formulários e códigos SIM são fictícios.
